FM FRONTERA WEB 2.0 — PROTOTIPO INICIAL

1. Abrir index.html en Chrome o Edge para ver el diseño.
2. Para publicar: crear repositorio público en GitHub, subir index.html, styles.css y script.js a la raíz y activar Settings > Pages > Deploy from a branch > main / root.
3. El reproductor está intencionalmente sin conexión: colocar la URL HTTPS real del streaming en STREAM_HTTPS_URL dentro de script.js. No utilizar HTTP en una página HTTPS.
4. Las galerías y la publicidad contienen espacios de muestra. Sustituir por fotos y banners autorizados.
5. Verificar el teléfono de WhatsApp, enlace a Play Store, correo y dirección antes de publicar oficialmente.
6. El dominio personalizado se configura después de probar la dirección github.io.
